## Publicaciones de X
La cuenta https://x.com/Ruta5Survias está enlazada desde el sitio oficial.
Se integra mediante el widget oficial, sin scraping ni credenciales. La carga tiene tiempo límite, reintento y enlace directo siempre visible. La integración no interpreta un fallo de carga como ausencia de publicaciones ni convierte publicaciones en alertas operacionales verificadas.
Para consulta estructurada, clasificación o monitoreo automático se requeriría una integración de servidor con acceso autorizado a la API de X; esta demo no implementa ese servicio.
