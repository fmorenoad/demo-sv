# demo-sv · Survías

Prototipos navegables y análisis técnico para la propuesta de evolución digital de la
Oficina Virtual de Survías (Ruta 5, tramo Talca – Chillán).

| Carpeta / archivo | Contenido |
|---|---|
| `mockups/` | Proyecto React + Vite con tres demos: sitio público + Oficina Virtual (`/`), landing editorial (`/landing/`) y landing de servicio (`/landing2/`). Publicadas en https://survias.iwan.cl |
| `informe-oficina-virtual-survias.md` | Informe técnico del portal actual: módulos, stack, hallazgos y propuestas |

Para correr las demos: `cd mockups && npm install && npm run dev`. Detalles en `mockups/README.md`.

Todos los datos de las demos son ficticios. Los documentos comerciales no forman parte de este repositorio.
